## Getting Started

To run the portfolio on your local machine:

1. Clone the repository:

   ```bash
   git clone YOUR-PORTFOLIO-REPOSITORY-URL
   ```

2. Navigate into the project directory:

   ```bash
   cd john-emmanuel-portfolio
   ```

3. Open `index.html` in your browser, or use the Live Server extension in Visual Studio Code.

**Note:** Replace `YOUR-PORTFOLIO-REPOSITORY-URL` with your actual GitHub repository URL.
